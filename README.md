# PARTY GO 2016

Локальная браузерная игра для вечеринки. QR существа сканируется камерой телефона, после чего показываются название, 2D-картинка и XP. После поимки эта же картинка появляется в коллекции.

## Добавить нового персонажа
1. Положи картинку в `public/images/`, например `dragon.png`.
2. Добавь один объект в `data/creatures.json`:

```json
{
  "id": "dragon",
  "name": "Dragon",
  "tier": "normal",
  "rarity": "ОБЫЧНЫЙ",
  "xp": 250,
  "image": "/images/dragon.png"
}
```

`qrPayload` можно не писать — сервер сам использует `PARTYGO:dragon`. QR создастся автоматически при запуске. Не нужно менять HTML, JS или другие списки.

## Запуск
```powershell
npm install
npm start
```

Для камеры телефона используй HTTPS (например, Cloudflare Tunnel).
